FAQ

Frequently Asked Questions

What is JSWIN?

JSWIN is a static gaming-style website demonstration built for GitHub Pages. It does not operate real-money games.

Does it work on mobile?

Yes. The layout adapts to desktop, tablet and mobile screen sizes.

Can I change the branding?

Yes. Text, logo, colors, cards and sections are all in editable HTML and CSS files.

Can I connect a real backend?

This package intentionally contains no real-money, payment or wagering backend. A lawful application would need its own compliant backend and required licensing.
