# JSWIN GitHub Pages Website

## Structure
- `index.html` — main page
- `css/style.css` — all styling
- `js/app.js` — front-end interactions
- `images/` — place your images here

## GitHub Pages
Upload the contents of this folder to the root of your GitHub repository, then enable Settings → Pages → Deploy from branch → `main` → `/ (root)`.

This is a static front-end demo. It does not process real-money transactions or store login credentials.
